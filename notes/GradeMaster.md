# GradeMaster

Adaptive quiz system for grades 3–5.

## Stack
FastAPI · Oracle DB · Redis · ChromaDB · React 18

## Running locally
- Backend: `uvicorn app.main:app --reload` → localhost:8000
- Frontend: `cd frontend && npm run dev` → localhost:5173
